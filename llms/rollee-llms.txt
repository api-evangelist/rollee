## API Reference
- [Getting Started](https://developers.getrollee.com/reference/getting-started-with-your-api.md): This page will help you get started with your new API.
- [Get account information](https://developers.getrollee.com/reference/get_accounts-id.md): Get information related to an account
- [Delete an Account](https://developers.getrollee.com/reference/delete_accounts-id.md): Delete an account belonging to a User
- [Disconnect account](https://developers.getrollee.com/reference/post_accounts-id-disconnect.md): Set the account as disconnected so that Rollee will not update it anymore until it gets reconnected
- [Account reconnect session](https://developers.getrollee.com/reference/post_accounts-id-reconnect.md): Create a reconnect session for an account
- [Get Accounts](https://developers.getrollee.com/reference/get_users-id-accounts.md): Get all accounts belonging to a User
- [Get activity](https://developers.getrollee.com/reference/get_accounts-id-activity.md): Get activity information of an account. Available for gig economy platforms only.
- [Get assets](https://developers.getrollee.com/reference/get_accounts-id-assets.md): Get assets information of an account. Available for gig economy and tax.
- [Get bank informations](https://developers.getrollee.com/reference/get_accounts-id-banking-info.md): Get bank information of an account. Available for gig economy and tax.
- [Get bonuses](https://developers.getrollee.com/reference/get_accounts-id-bonuses.md): Get bonuses information of an account
- [Get documents](https://developers.getrollee.com/reference/get_accounts-id-documents.md): Get documents information of an account
- [Get employment](https://developers.getrollee.com/reference/get_accounts-id-employment.md): Get employment information of an account. Available for gig economy and tax.
- [Get income](https://developers.getrollee.com/reference/get_accounts-id-income.md): Get income information of an account. Available for gig economy and tax.
- [Get performance](https://developers.getrollee.com/reference/get_accounts-id-performance.md): Get performance information of an account. Available for gig economy platforms only.
- [Get profile](https://developers.getrollee.com/reference/get_accounts-id-profile.md): Get profile information of an account. Available for gig economy and tax.
- [Get transactions](https://developers.getrollee.com/reference/get_accounts-id-transactions.md): Get transactions of an account
- [Get trips](https://developers.getrollee.com/reference/get_accounts-id-trips.md): Get trips information of an account. Available for gig economy platforms only.
- [Get vehicles](https://developers.getrollee.com/reference/get_accounts-id-vehicles.md): Get vehicles information of an account. Available for gig economy platforms only.
- [Get wallet](https://developers.getrollee.com/reference/get_accounts-id-wallet.md): Get wallet information of an account
- [Get data settings](https://developers.getrollee.com/reference/get_data-settings.md): Get current data collection configuration
- [Get Data Sources](https://developers.getrollee.com/reference/get_data-sources.md): Get available data sources for a partner
- [Refresh a session](https://developers.getrollee.com/reference/post_sessions-session-refresh-1.md): Refresh a session that has expired
- [Create JWT Token](https://developers.getrollee.com/reference/get_token-refresh-1.md): Generate a new valid JWT Token
- [Get Users](https://developers.getrollee.com/reference/get_users.md): Get informations for all users
- [Create User](https://developers.getrollee.com/reference/post_users.md): Create a user with optional metadata
- [Get User](https://developers.getrollee.com/reference/get_users-id-1.md): Get informations for a specific user
- [Update user metadata](https://developers.getrollee.com/reference/put_users-id-1.md): Update an user's metadata. The previous metadata will be replaced
- [Delete user](https://developers.getrollee.com/reference/delete_users-id.md): Delete a User and its associated Accounts
- [Get performance index](https://developers.getrollee.com/reference/get_users-id-performance-index.md): Get performance index for the user. Available for gig economy platforms only.
- [Create a session for an user](https://developers.getrollee.com/reference/post_users-id-sessions-new.md): Create a session for a user (intended for users created with the API v0.3)
- [Lists configured webhooks](https://developers.getrollee.com/reference/get_webhooks.md): List all the webhooks that are currently configured (both enabled and disabled ones)
- [Webhook configuration for Accounts Events](https://developers.getrollee.com/reference/put_webhooks-accounts.md): Call to configure webhooks and receive Rollee's Events for the users' accounts. Please bear in mind that this is a full replace operation for the webhook attributes, so you need to provide all the parameters.
- [Webhook configuration for Endpoint Events](https://developers.getrollee.com/reference/put_webhooks-endpoints.md): Call to configure your Webhooks and receive notifications as soon as new data has been fetched for a specific account. Please bear in mind that this is a full replace operation for the webhook attributes, so you need to provide all the parameters.
- [Webhook configuration for Multi Endpoint Events](https://developers.getrollee.com/reference/put_webhooks-multi-endpoints.md): Call to configure your Webhooks and receive notifications as soon as data from several different endpoints is fetched. Please bear in mind that this is a full replace operation for the webhook attributes, so you need to provide all the parameters.
- [Webhook configuration for Rollee Connect Events](https://developers.getrollee.com/reference/put_webhooks-rollee-connect-events.md): Call to configure your Webhooks and receive notifications for each rollee connect event. Please bear in mind that this is a full replace operation for the webhook attributes, so you need to provide all the parameters.
- [Webhook configuration for Users Events](https://developers.getrollee.com/reference/put_webhooks-users.md): Call to configure your Webhooks and receive Rollee's Events for your Users. Please bear in mind that this is a full replace operation for the webhook attributes, so you need to provide all the parameters (even optionals if these were set before and want to keep them).
- [Delete a webhook configuration](https://developers.getrollee.com/reference/delete_webhooks-type.md): Delete a particular webhook configuration (can be accounts, users, rollee_connect_events, endpoints or multi_endpoints)
- [Lists configured webhooks](https://developers.getrollee.com/reference/get_webhooks-v2.md): List all the webhooks that are currently configured (both enabled and disabled ones)
- [Getting Started](https://developers.getrollee.com/reference/getting-started-with-your-api-copy.md): This page will help you get started with your new API.
- [List all companies](https://developers.getrollee.com/reference/get_companies.md): Retrieve information about all companies associated with a specific person
- [Create a new company](https://developers.getrollee.com/reference/post_companies.md): creates a new company that belongs to a specific client
- [Delete an existing company](https://developers.getrollee.com/reference/delete_companies-id.md): Deletes a company that belongs to a specific client
- [Get company info](https://developers.getrollee.com/reference/get_companies-id.md): Retrieve information about a specific company
- [Get company accounts](https://developers.getrollee.com/reference/get_companies-id-company-accounts.md): Get all company accounts given a particular company
- [Get company account information](https://developers.getrollee.com/reference/get_company-accounts-id.md): Get company account information
- [Company Account reconnect session](https://developers.getrollee.com/reference/post_company-accounts-id-reconnect.md): Create a reconnect session for a company account
- [Webhook configuration for Company Accounts Events](https://developers.getrollee.com/reference/put_company-v0-5-webhooks-accounts.md): Call to configure your Webhooks and receive Rollee's Events for your Company Accounts. Please contact Rollee team if you're planning to use Webhooks.
- [Webhook configuration for Endpoint Events](https://developers.getrollee.com/reference/put_company-v0-5-webhooks-endpoints.md): Call to configure your Webhooks and receive notifications as soon as new data has been fetched for a specific company account. Please contact Rollee team if you're planning to use Webhooks.
- [Lists configured webhooks](https://developers.getrollee.com/reference/get_webhooks-1.md): List all the webhooks that are currently configured (both enabled and disabled ones)
- [Get company absences](https://developers.getrollee.com/reference/get_company-accounts-id-absences.md): Get Absences informations of a company account
